# Квиз АЦХ — День Рождения Церкви

Праздничный квиз для проведения с проектора: вопросы с таймером, слайды с ответами,
таблица баллов, печатные бланки. Next.js 14 + Tailwind, без бэкенда.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000. Для продакшена — `npm run build && npm start`.

## Как проходит игра

1. **Заставка раунда** → кнопка «Начать раунд».
2. **Вопросы** — каждый с круговым таймером. Последние 10 секунд тикают громче.
3. **Время вышло** — звучит сигнал, показывается оверлей и через несколько секунд
   вопрос сам сменяется следующим (можно нажать «Остаться» или «+15 с»).
4. После последнего вопроса — слайд **«Ответы на раунд N»**, затем **ответ на каждый
   вопрос** отдельным слайдом (правильный вариант подсвечен).
5. После всех раундов — **финал** с конфетти и переход к таблице баллов.

Прогресс игры, правки в редакторе, команды и настройки сохраняются в браузере
(localStorage), так что перезагрузка страницы ничего не теряет.

## Горячие клавиши (на экране игры)

| Клавиша | Действие |
| --- | --- |
| `→` / `Пробел` / `Enter` | Следующий слайд |
| `←` | Предыдущий слайд |
| `P` | Пауза / старт таймера |
| `+` | +15 секунд |
| `M` | Музыка вкл/выкл |
| `F` | Полный экран |

## Звук

- **Эффекты** (тик таймера, «время вышло», переходы, фанфары) синтезируются через
  Web Audio API — файлов не нужно.
- **Фоновая музыка** по умолчанию тоже генерируется: спокойная между вопросами,
  напряжённая во время отсчёта.
- **Свой трек**: ⚙️ Настройки → «Свой файл» (действует до перезагрузки), либо положите
  `public/music/background.mp3` — тогда он подхватится автоматически.
- Громкость, автопереход, задержка перед ним и автозапуск таймера — в ⚙️ Настройках.

Браузеры включают звук только после первого клика на странице — это нормально.

## Структура

```
app/            layout (шрифты Unbounded + Comfortaa), глобальные стили
components/     QuizApp (оболочка), GameScreen, MenuScreen, LeaderboardScreen,
                AdminScreen, DesignsScreen, SoundControls, TimerRing, Confetti, Icons
lib/            types, quizData (вопросы), quiz (слайды/утилиты), audio (звук), storage
public/music/   место для background.mp3
```

Вопросы можно править в разделе «Редактор» прямо в браузере (есть экспорт/импорт JSON),
а исходные данные — в `lib/quizData.ts`.
